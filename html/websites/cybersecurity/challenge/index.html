Can you challenge TaraSec?

We are not asking you to trust our cybersecurity idea. We are asking you to test it, attack the demo, question the design and help us make it better.

TaraSec explores a simple governance idea: networks should cooperate when they see abusive traffic, so an attacker stopped by one participant becomes less useful against the next.

Join the Pizza Challenge How it works
The idea

Internet does not only need more security technology. It needs better cooperation.

Firewalls already stop attacks every day. TaraSec asks what happens if that knowledge is shared safely with other participating networks.

1. A network rejects abuse

A participating firewall sees traffic it considers malicious or unacceptable and rejects it.

2. Partners learn from it

The event can be reported through TaraSec so cooperating participants have more context about later traffic from the same source.

3. Attacks become less profitable

The goal is not surveillance. The goal is to reduce the value of compromised machines and repeated abusive traffic.

Why pizza?

Because security testing is more interesting when it is social.

The event format is intended for universities and student communities: short introduction, hands-on challenge, discussion and pizza.

The challenge is about learning and testing, not attacking unrelated systems.

What should you challenge?

Everything that matters: whether cooperative tagging is useful, whether false positives can be controlled, whether privacy is protected, whether NAT and mobile networks can participate, whether routing works at scale, and whether the incentives make sense for ISPs.

TaraSec is a reference implementation, not a claim that our current code is the final answer. If students, researchers, ISPs or open-source developers build a better implementation of the cooperative model, that is a success.

Challenge rules

✓ Use only the systems designated by the event organiser.
✓ Follow the challenge instructions and scope.
✓ Report unexpected behaviour and weaknesses.
✓ Question both the software and the idea.
✗ Do not attack third-party networks, accounts or devices.
