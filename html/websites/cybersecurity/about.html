About TaraSec

Cooperative cybersecurity through better governance

About Us

The Internet doesn't need more security technology. It needs better security governance.

The Internet already has firewalls, intrusion detection, threat intelligence, artificial intelligence and increasingly sophisticated security tools. Yet networks still largely defend themselves independently.

TaraSec explores a different approach: cooperation.

The network receiving harmful traffic can see what happened. The network that sent the traffic is in a better position to identify and control its source. TaraSec provides a way for those networks to share enough information to act together.

We do not claim that the individual technologies behind TaraSec are particularly novel. Our contribution is the collaborative model: the rules, responsibilities, information exchange and incentives that allow independent networks to help protect one another.

Our Mission

Make cooperation part of Internet security

Cybercrime is not only a technology problem. It is also a coordination problem. A receiving firewall may know that traffic is malicious, while the sending ISP knows who controls the connection that produced it. Today those pieces of information are often separated.

TaraSec asks what becomes possible when networks can warn and assist one another. A receiving network can report harmful traffic. The responsible network can investigate, tag or contain the source. Other cooperating networks can then make better decisions about later traffic from that source.

The objective is not to centralize control of the Internet. It is to let independent networks cooperate while retaining responsibility for their own users, policies and decisions.

  • Receiving networks contribute evidence
  • Sending networks remain responsible for their own users
  • Cooperation can make compromised infrastructure less useful to attackers
  • Participants remain free to implement the model differently
What We Build

A reference implementation, not a technology monopoly

TaraSec's software exists to demonstrate, test and challenge the collaborative model. It combines ordinary networking and security components into a working environment where networks can exchange evidence, request assistance and test cooperative containment.

That implementation is not intended to dictate how every ISP, firewall vendor or network operator must build TaraSec. A university, ISP, security company or open-source community should be able to implement the same governance model using different technology.

If someone builds a better implementation of TaraSec, that is a success for TaraSec.

Our Values

Governance is part of the architecture

A system that may influence how independent networks treat one another must earn trust through scrutiny, accountability and broad participation.

Transparency

The model should be open to inspection and criticism.

Transparency

Security infrastructure should not depend on trusting a black box. Researchers, operators and users should be able to examine assumptions, evidence and implementation choices.

Cooperation

Networks are stronger when they help one another.

Cooperation

TaraSec is built around independent participants contributing different pieces of information and acting within their own responsibilities.

Independent governance

Global cooperation should not depend on one commercial owner.

Independent governance

TaraSec is developed by Taransvar, a Norwegian nonprofit. We want universities, ISPs, researchers, security professionals, students and other participants to challenge both the technology and the governance.

An Open Challenge

Don't just trust TaraSec. Try to prove it wrong.

We invite universities, ISPs, security professionals, students and people with no cybersecurity background to test the idea. Ask whether cooperation actually improves containment. Look for privacy problems, incentives that fail, abuse scenarios, technical weaknesses and better governance models.

If the technology can be improved, improve it. If the governance can be improved, improve that too. The objective is not to build another cybersecurity product. It is to find a better way for the Internet to defend itself collectively.
